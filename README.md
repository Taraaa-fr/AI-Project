# Who's checking the machine? An AI explainer

A one-page website explaining artificial intelligence for a general audience: what it is, its benefits, its risks, and possible futures, built around one idea: AI needs human supervision.

- `index.html`: content (semantic HTML)
- `styles.css`: colours, layout, responsive design
- `script.js`: optional enhancements (flip cards, current-section highlight)
- `assets/`: SVG diagrams
